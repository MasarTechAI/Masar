Masar Tested Why should a business trust it?

Masar Tested.
Here’s exactly what that means.

“Verified” sounds official and says nothing. A Masar Test Report states what was tested, on what, with what result — and what it doesn’t cover.

  1. 01

    Documented

    The builder declares what the agent does, what it can’t do, what data it touches, and where that data is processed.

  2. 02

    Task test

    Run against a representative test set for its workflow — for example, 300 real-format customer messages, most in Saudi dialect.

  3. 03

    Consistency

    The same inputs are run repeatedly. An agent that answers differently each time doesn’t pass.

  4. 04

    Safety & permissions

    Prompt-injection attempts, requests for other customers’ data, off-topic requests. Permissions are checked against what the agent actually needs.

  5. 05

    Re-tested

    On every new version, and every 90 days. A report carries a date and a version — it expires.

Masar Tested means

  • ✓The agent passed Masar’s published test for a defined task
  • ✓Results are reported for a specific version and date
  • ✓Its data access, permissions and limitations are disclosed
  • ✓It is re-tested whenever it changes

It does not mean

  • ✕A government certification or official accreditation
  • ✕Approval by SDAIA, the NCA or any other regulator
  • ✕The same results on your data — that’s why you test on your data first
  • ✕A security audit or a legal / PDPL compliance review
  • ✕That the agent can’t make mistakes
